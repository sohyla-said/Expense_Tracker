# 💰 Expense Tracker Application

A Python-based **Expense Tracker** application for managing personal finances.  
The project now includes a **Flask REST API** and a **Streamlit UI** for browsing, adding, updating, deleting, filtering, and exporting expenses with monthly budget tracking.

The application can be used in two ways:
1. **Flask REST API** – expose expense, category, and budget features as HTTP endpoints.
2. **Streamlit UI** – interact with the app from a browser with tables, filters, and edit/delete controls.
---

## 📌 Features

- **Add Expenses** with description, amount, category, and date.
- **Update Expenses** by ID (edit description, amount, or category).
- **Delete Expenses** by ID.
- **View Current Month Expenses** in a table with edit, delete, and export actions.
- **View Expenses by Selected Month** with budget details and export actions.
- **Browse Available Categories** and add new categories from the UI.
- **Filter by Category** to see only specific expenses.
- **Check Monthly Budget** and compare budget vs spent.
- **Set and View Monthly Budget** for a chosen month.
- **Export to CSV** for the current month or a selected month.
- **Data Persistence** — stores all data in a sqlite DB.

---

## 🛠️ Technologies Used

- **Python 3**
- **Flask** (for REST APIs)
- **Streamlit** (for the browser UI)
- **Pandas** (for table rendering in the UI)
- Built-in modules:
- `datetime` (for handling dates)

## 🚀 How to Run

1. **Clone or Download the Project**  
   ```bash
   git clone https://github.com/your-username/expense-tracker.git
   cd expense-tracker
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt  
   ```

3. **Start the Flask API**
   ```bash
   python run.py
   ```

4. **Start the Streamlit UI**
   ```bash
   streamlit run UI/streamlit_app.py
   ```

## 🌐 API Notes

The main API routes are exposed under `/api` and include:

- `POST /api/expenses/add`
- `PUT /api/expenses/update/<id>`
- `DELETE /api/expenses/delete/<id>`
- `GET /api/expenses`
- `GET /api/expenses/month?month=<month>`
- `GET /api/expenses/category?category=<category>`
- `GET /api/expenses/export`
- `GET /api/expenses/month/export?month=<month>`
- `POST /api/categories/add`
- `GET /api/categories`
- `GET /api/budget/month?month=<month>`
- `GET /api/budget/check?month=<month>`
- `POST /api/budget/set?month=<month>&budget=<budget>`
